# Inside the hoogin registry repo

Read this only when working *inside* this repository — either authoring a new
`form-*.field.tsx` or editing the shipped form components. Consumers of
`@hoogin/form-fields` never need it.

## Loop after editing a form

From the repo root:

1. `bun run scripts/sync.ts` — regenerates `registry/ui/forms/*` from
   `example/src/hoogin/` **and** `example/src/config/registry.ts`.
2. `cd example && bun run typecheck` — field-type rules only fail here.
3. `cd example && bun run lint`, then `bun run build`.
4. When a registry item changed: `bunx --bun shadcn@latest build` and
   `bunx --bun shadcn@latest registry validate ./registry.json`.

## Shipping a new field

Write it under `example/src/hoogin/ui/forms/` first (that is the dev site), then
add it to the `form-fields` item in `registry/ui/registry.json`:

```json
{
  "path": "forms/form-foo.field.tsx",
  "type": "registry:ui",
  "target": "hoogin/ui/forms/form-foo.field.tsx"
}
```

`target` is relative to the consuming app's alias root (normally `src/`). Every
file of a multi-file item needs its own entry — `sync.ts` copies each declared
file and warns about `ui/` files that belong to no item.

## Reference implementations

- `example/src/hoogin/blocks/signup-page/signup-form.tsx` — auth form, inline
  cross-field validator, full-width submit button instead of `FormFooter`.
- `example/src/hoogin/blocks/signin-page/signin-form.tsx` — minimal auth form.
- `example/src/routes/docs/components/form-fields.tsx` — every field in one
  form; also the docs-page pattern (`ComponentDoc` / `DocSection` / `Preview` /
  `CodeBlock` / `PropsTable`).
- `example/src/routes/docs/blocks/admin-page.tsx` — entity form inside a sheet,
  with the `PaymentForm` + columns + schema split a real consumer would write.

## Docs pages

A new field component wants a `example/src/routes/docs/components/<name>.tsx`
route plus an entry in `example/src/config/registry.ts` (generated by
`sync.ts`) so the docs site can render the install command. Skip it if the field
is only an internal addition.
